# Recipe Picker

A responsive recipe picker built with HTML, CSS, and vanilla JavaScript.

## Live site

Visit [Recipe Picker on GitHub Pages](https://waldex451.github.io/recipes/).

## Features

- Browse recipes by meat, fish, or vegetarian category.
- Pick a random recipe for dinner.
- Responsive layout with recipe images.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deployment

The site is hosted with GitHub Pages from the `main` branch.
